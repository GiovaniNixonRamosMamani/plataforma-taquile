# Plataforma de artesanos de Taquile

Proyecto web del curso Desarrollo Basado en Plataformas I (SIS302), UNA-Puno.
Plataforma para una asociación de artesanos textiles de la isla Taquile (caso de trabajo del curso).

## Integrantes

- Giovani Nixon Ramos Mamani · usuario de GitHub: GiovaniNixonRamosMamani

## Cómo abrir el proyecto

Abrir la carpeta en Visual Studio Code y servir `index.html` con el servidor local (Live Server).

## Estructura

- `index.html`: página de inicio.
- `pedido.html`: formulario principal (registrar un pedido, historia HU-02).
- `css/estilos.css`: estilos.
- `js/pedido.js`: mensajes de error del formulario.
- `img/`: imágenes del proyecto.
